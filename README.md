# Веб Анатомия — движение как часть формы

[Открыть коллекцию анимаций](https://aysad26.github.io/web-anatomy-motion/mobile/)

Интерактивная коллекция из 18 первых экранов: волны по рельефу, частицы, оптические эффекты, растр и фрагментация знака. Оформления переключаются на странице; ссылки с якорями `#01`–`#18` открывают отдельные сцены.

На больших экранах кольца расходятся реже. Переходы по рельефу сглажены, чтобы линии яснее передавали форму знака. Сцены реагируют на указатель и касание; автопроигрывание можно приостановить.

Для локального просмотра запустите из корня репозитория `python -m http.server 8000` и откройте `http://localhost:8000/mobile/`. Исходные файлы находятся в `mobile/` и `scenes/`, графика — в `assets/`.
